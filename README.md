# BizMate - 자영업자 수익 분석 서비스

BizMate는 자영업자가 매출, 지출, 상품 원가를 함께 관리하고 실제 수익 구조를 파악할 수 있도록 돕는 웹서비스입니다.

기존 포스기는 매출 관리 중심이지만, BizMate는 POS 매출 파일과 지출·원가 정보를 통합해 자영업자가 실제 수익 구조를 확인하도록 돕는 서비스입니다.

## 서비스 목표

자영업자는 포스기에서 판매량과 매출을 확인할 수 있지만, 매출만으로는 실제 수익을 파악하기 어렵습니다.

BizMate는 매출 데이터에 지출 정보와 상품별 추정 원가를 결합하여 다음 정보를 한 화면에서 확인할 수 있도록 합니다.

- 기간별 총매출, 총지출, 순이익
- 상품별 판매량과 매출
- 상품별 예상 마진
- 지출 항목별 합계와 비중
- 매출·지출 변화 추이
- 매장 운영에 필요한 기본 경영 인사이트

## 주요 기능

### 대시보드

- 오늘의 매출, 지출, 순이익, 주문 수 표시
- 최근 매출 추이 차트
- 인기 상품 TOP 3
- 매출·지출 데이터를 활용한 핵심 지표 확인

### 상품 관리

- 상품 목록 조회
- 상품 등록
- 판매가와 추정 원가 입력
- 예상 마진 자동 계산
- 상품 정보 수정 및 삭제

### 매출 관리

- 매출 목록 조회
- 매출 직접 등록
- 매출 정보 수정 및 삭제
- CSV/Excel 파일 업로드 화면
- 파일 미리보기, 열 매핑, 데이터 확인 흐름

### 지출 관리

- 지출 목록 조회
- 지출 직접 등록
- 지출 정보 수정 및 삭제
- 지출 파일 업로드 및 열 매핑 화면
- 지출 내역 확인 및 보완

### 분석 리포트

- 기간별 총매출, 총지출, 순이익, 순이익률
- 일별 또는 주별 매출 추이
- 상품별 매출 및 판매량 순위
- 지출 분류별 합계와 비중
- 상품별 예상 마진 분석
- 이전 기간과 비교한 매출 변화

## 기술 스택

- Java 11
- Apache Tomcat 9
- Servlet, JSP, JSTL/EL
- HTML, CSS, JavaScript
- Chart.js
- JDBC/DAO 예정
- MySQL 예정

## 현재 구현 범위

- 공통 사이드바와 헤더 구성
- 대시보드 UI와 샘플 차트 표시
- 상품 관리 화면 구성
- 상품 목록 조회 및 등록 기능의 Servlet·HttpSession 연동
- 매출·지출 목록, 등록, 수정 화면 구성
- 매출·지출 파일 업로드 흐름 구성
- 파일 미리보기, 열 매핑, 데이터 확인 화면 구성
- JavaScript 기반 입력값 검사와 마진·합계 계산

## 향후 개발 계획

- 회원가입, 로그인, 로그아웃 기능 구현
- 사용자별 상품·매출·지출 데이터 관리
- 상품 수정·삭제 기능을 서버 세션 및 DB와 연결
- 매출·지출 CRUD 기능을 Servlet과 연결
- DB 및 JDBC/DAO 도입
- 실제 CSV/Excel 파일 파싱과 데이터 검증 구현
- 실제 데이터를 활용한 대시보드와 분석 리포트 구현

## 향후 확장 기능

현재는 매출, 지출, 원가 데이터를 기반으로 한 분석 기능을 우선 구현합니다.

추후에는 분석 결과를 바탕으로 다음과 같은 AI 경영 코칭 기능을 추가할 계획입니다.

- 매출 감소 원인 분석
- 상품별 판매 전략 추천
- 지출 증가 항목 알림
- 마진이 낮은 상품 안내
- 매장 운영을 위한 맞춤형 경영 조언

AI 기능은 핵심 데이터 관리와 분석 기능이 안정적으로 완성된 뒤 확장 기능으로 추가할 예정입니다.
