# BizMate - AI 경영도우미

BizMate는 자영업자가 매출과 지출을 관리하고, 경영 현황을 파악할 수 있도록 돕는 웹서비스입니다.

웹서비스프로그래밍 수업 진도에 맞춰 Servlet/JSP 기반으로 개발하고 있습니다.

## 주요 목표 기능

- 매출·지출 현황을 확인하는 대시보드
- 매출·지출·상품 등록 및 관리
- CSV/Excel 파일을 통한 데이터 가져오기
- 기간별 매출·수익 분석
- AI 기반 경영 코칭

## 기술 스택

- Java 11
- Apache Tomcat 9
- Servlet(javax.servlet), JSP, EL/JSTL
- HTML, CSS, JavaScript
- Chart.js

## 현재 진행 상황

### 공통 화면 및 대시보드

- 사이드바와 헤더 등 공통 화면 구성
- 매출·지출·상품 관리 화면 구성
- 샘플 데이터를 활용한 대시보드 및 차트 표시

### 상품 관리

- Product 모델 작성
- Servlet에서 상품 목록을 조회하고 JSP로 전달
- JSTL/EL을 활용한 상품 목록 및 예상 마진 출력
- HttpSession을 활용한 임시 상품 목록 보관
- 세션에 상품 목록이 없을 때 샘플 상품 3개 생성
- POST 요청을 통한 상품 등록 및 서버 입력값 검사
- 등록 후 목록으로 redirect하여 새로고침에 따른 중복 제출 방지
- 등록 화면에서 예상 마진 계산 및 입력값 검사

### 매출·지출 관리

- 목록·등록·수정 화면 구성
- 파일 선택·미리보기·항목 매핑·검토 화면 구성
- 임시 데이터를 활용한 화면 동작 및 입력값 검사

## 현재 구현 범위

- 상품 등록과 목록 조회는 서버 세션에 연결되어 있습니다.
- 상품 수정·삭제는 아직 세션 목록과 연결되지 않았습니다.
- 매출·지출 화면은 임시 데이터와 JavaScript 기반 화면 동작을 사용합니다.
- 파일 가져오기는 화면 흐름을 구성한 단계이며, 실제 CSV/Excel 파일 파싱과 저장은 구현 전입니다.
- 데이터베이스, 실제 데이터 기반 분석, AI 경영 코칭은 아직 연결하지 않았습니다.

현재 상품 데이터는 DB에 저장되지 않습니다. 세션이 만료되면 추가한 상품이 사라지며, 사용자 간에 상품 목록을 공유하지 않습니다.

## 향후 개발 계획

- 상품 수정·삭제 기능을 세션 목록과 연결
- 수업 진도에 맞춰 DB 및 JDBC/DAO 도입
- 세션 기반 상품 저장·조회를 DB 기반으로 전환
- 매출·지출 등록·조회·수정·삭제 기능 구현
- CSV/Excel 파일 파싱 및 데이터 검증 구현
- 실제 데이터를 활용한 경영 분석 및 AI 코칭 연동
