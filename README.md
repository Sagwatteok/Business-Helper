# BizMate - AI 경영도우미

BizMate는 자영업자가 매출과 비용을 더 쉽게 관리하고, 경영 현황을 파악할 수 있도록 돕는 웹서비스입니다.

## 주요 기능

- 사업장별 매출·비용 현황 확인
- 상품 및 비용 관리
- CSV/Excel 매출 파일 업로드와 데이터 검증
- 기간별 매출·수익 분석
- AI 기반 경영 코칭

## 기술 스택

- Java 11
- Apache Tomcat 9
- Servlet, JSP, JSTL/EL
- HTML, CSS, JavaScript

## 진행 현황

현재는 공통 화면 구조와 대시보드 UI를 구축하는 단계입니다. 데이터베이스와 실제 CRUD 기능은 수업 진도에 맞춰 순차적으로 추가합니다.
